# Verified Datasheet Catalog

This catalog is maintained from datasheets supplied by the user in ChatGPT and reviewed before being added.

Each datasheet entry may contain multiple product variants. For example, one solar-module PDF can contain 650 W, 660 W, and 670 W variants, each with its own Vmp, Voc, Imp, and Isc values.

The public repository stores extracted engineering fields and the original source filename only. Source PDF files are not published here by default.
