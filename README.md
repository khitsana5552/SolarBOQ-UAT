# SolarBOQ-UAT

UAT update feed and source snapshot for the Solar BOQ prototype.

- `app/` — current UAT application source
- `update/uat-manifest.json` — updater manifest
- `packages/` — versioned update packages

User project data, BOQ pricing, equipment database, datasheets, and saved diagrams remain on the local Windows machine and are not stored here by the updater.
