# Solar BOQ UAT v0.3.3

- Added a dedicated **Datasheet Database** page.
- Shows the central ChatGPT-reviewed datasheet catalog separately from local Equipment Library records.
- Supports search and type filters for Module, Inverter, and Rapid Shutdown datasheets.
- One datasheet can contain multiple variants (for example 650/660/670 W).
- `Use on this PC` copies all verified variants from the central catalog into the local Equipment Library for String Design.
- Source PDF filenames and verification status are visible in the database.
- The central catalog can be refreshed without reinstalling or updating the application.

The source PDF itself is not published in the public repository; only reviewed engineering fields and its filename are stored in the catalog.
